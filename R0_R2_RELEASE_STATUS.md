## Current evidence

- The R0/R1 acceptance run passed **186/186** checks. The final combined scoped R0/R1/R2 run passed **314/314** across 24 explicit test files. Later-phase feature suites are excluded. Exact commands/counts are recorded in R2_ACCEPTANCE.md.
- Production frontend/TypeScript/Vite/PWA build and API bundling have passed. Full lint, configuration, security-pattern and infrastructure-contract checks passed. Final SAM lint/build/browser artifact versions are recorded in the detailed acceptance/deployment reports; static checks do not establish deployed security.
- Actual browser interactions use isolated production-build synthetic origins, separate from the user's planning origin. Native IndexedDB, app-shell worker, cache eviction, offline reload/reconnect, waiting update and R2 personal workflows were checked; fault-injected models are identified separately from native evidence.
- At **11 October 00:01–00:21 IST**, five real local city selections returned HTTP 200 and 72 forecast points. New Delhi, Noida, Gurugram and Mumbai had recent selected PM2.5 observations; Bengaluru retained its correctly labeled 7 October measurement. Three recent NCR selections were non-reference AirGradient instruments. This is a dated, bounded check, not nationwide coverage or calibration/accuracy proof; see MONITOR_COVERAGE.md.
- R2 style regressions cover control contrast, target sizes, long-content wrapping and reduced-motion declarations. Browser/device evidence is confined to Codex's Chromium in-app browser and emulated sizes; physical phones, Safari/Firefox, actual installer flow and screen-reader/hardware access remain unverified.
- AWS account identity, deployment, current credits, regional charges, HTTPS/CORS/CSP/IAM/WAF operation and production restore/alarms remain pending.
