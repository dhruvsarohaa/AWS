# Airday: three-minute hackathon video

Record the deployed Amplify URL and a real provider response on the day of submission. Never replace unavailable air readings with unlabeled sample values. Use a school PE period as the concrete story; the same planner accepts any person's outdoor activity.

| Time      | Screen and narration                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:25 | **Problem.** “Bad-air days change ordinary outdoor plans. A teacher, worker, or parent needs a quick way to review tomorrow's exposure window, but a city-wide forecast and a station observation answer different questions.” Show the dashboard opening at an Indian location.                                                                                                                                                                                                                                                                        |
| 0:25–0:55 | **Location and forecast.** Start with the labelled Delhi preview, then select an Indian city or choose **Use my location** and allow the prompt. Choose **Tomorrow**. “Airday fetches a CAMS Global forecast through Open-Meteo. This is a regional model estimate, not a reading at this school and not official Indian AQI.” Show the date, retrieval timestamp, units, and attribution.                                                                                                                                                              |
| 0:55–1:20 | **Observed evidence.** Show the nearby station card with provider, station name, distance, and source timestamp. “The station is shown separately because it can disagree with the model.” If both CPCB and OpenAQ are connected, show both without averaging. If a source is missing or stale, show its explicit state and say so.                                                                                                                                                                                                                     |
| 1:20–2:10 | **One working decision loop.** Edit the seeded school example: PE, tomorrow's weekday, a school-chosen review threshold, permitted alternative hours and an available indoor option. Save. Inspect the activity's chart window. If available, choose a complete lower-value time; otherwise choose an actual feasible action, without fabricating a crossing. Enter its reason and show the evidence ID, persistence and follow-through. “This is a planning comparison; staff make the decision. Regional forecasts cannot establish safe conditions.” |
| 2:10–2:40 | **Built on AWS.** On the actual deployment, show Amplify and the stack. “Amplify hosts the interface. API Gateway and WAF protect the API; DynamoDB serves shared evidence. EventBridge and SQS refresh providers independently. Lambda preserves original timestamps and Secrets Manager keeps keys off the browser. SAM defines the deployment.” If deployment is still incomplete, show SAM validation and local operation, and explicitly say the cloud deployment has not run.                                                                     |
| 2:40–3:00 | **Close.** “The result is a usable, source-aware plan for one real outdoor activity. Anyone can use the same flow for a commute, sports period, or outdoor work. Forecasts are regional, station coverage varies, and the user keeps the final call.”                                                                                                                                                                                                                                                                                                   |

Before recording, verify that the deployed `/api/health` responds, the selected city's forecast returns values, and at least one configured station source returns an observation if station coverage is part of the narration. Keep the source timestamp visible in the recording. If no station is available, narrate the forecast-only state honestly.
